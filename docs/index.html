AI Video Studio

A free skill for Claude Code that teaches your AI agent to make narrated explainer videos with a cartoon presenter and mostly free tools, the way Ghaith Works makes its guides.

  1. First it asks you questions.

    Topic, audience, dialect, length, voice, presenter, your GPU, your budget, your channel. About twenty, in small batches, each with a suggested answer.

  2. Then it writes the script.

    Every line carries a presenter pose and what is on screen. You read it all before a single word is voiced.

  3. It voices, times and animates.

    Two takes per chapter, checked by Whisper. Every pose and box is keyed to a line. Nothing is timed by hand.

  4. You say when it ships.

    You review the cut. Uploads, and how to answer each platform's AI question, stay your decision.

Install in one copy

The skill is a folder of text: one SKILL.md and seven reference files. Copy it into your Claude Code skills folder, then ask Claude for a video.

  1. Download the repo, or clone it.
  2. Copy skills/ai-video-studio into ~/.claude/skills/.
  3. Start Claude Code and say: “make me a guide video about …”.
Terminal 
git clone https://github.com/Karthus3560/ai-video-studio-skill
cp -r ai-video-studio-skill/skills/ai-video-studio ~/.claude/skills/

# Windows (PowerShell)
Copy-Item -Recurse ai-video-studio-skill\skills\ai-video-studio "$HOME\.claude\skills\"
> claude
> make me a 5 minute guide about free AI voices, in Iraqi Arabic▌

Before you start

CostIs it really free?

The skill is free and MIT-licensed. You need a Claude subscription for Claude Code. Every other step has a free tool; paid tools are optional upgrades the skill names and lets you choose.

FilesWhat is in the skill?

Only text: instructions and short code snippets that explain each step. No art, no voices, no project files. Your agent builds everything in your folder, with your own art and voice.

UploadWill it upload videos for me?

Only when you say so, every time. The skill tells your agent to prepare the file, title, description and thumbnail, show them to you, and wait for your explicit go.

AI labelsWhat about AI-content labels?

YouTube, TikTok and Meta ask whether content is AI-generated or synthetic. The skill has your agent ask you how to answer, read the platform's current rules with you, and follow them. It never tells you to hide a disclosure a platform requires.

LanguagesDoes it work in Arabic?

It was built for an Iraqi Arabic and English channel. Every component handles right-to-left and left-to-right, and both language versions render from the same code.

MachineDo I need a strong PC?

A laptop with a 6 GB GPU was enough for local voices and songs. Without a GPU, use the online free tiers; Whisper and Remotion run on the CPU.
